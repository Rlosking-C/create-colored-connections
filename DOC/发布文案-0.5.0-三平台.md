## 一、Modrinth

### 1.1 Summary（列表页摘要）

```
Colorize Create's Factory Gauge recipe links with the 16 vanilla dyes, so dense and heavily crossed production lines stay readable at a glance.
```

### 1.2 Description（项目正文）

```markdown
Create's Factory Gauges draw a whole wall of connection lines in recipe mode. As a production line grows, those lines cross one another constantly, and because their colour only reflects recipe status, there is no way to tell which line belongs to which recipe. This mod lets you colour a connection line with any dye, so that colour also carries ownership.

## Features

**Dye a link.** Hold any of the sixteen vanilla dyes and right-click the connection line itself, not the gauge panel. Black dye restores the vanilla status colour. Dyeing is free by default, and a configuration option can make each dyeing action consume one dye.

**Dye a whole path at once.** Shift+right-click a gauge to begin a path, then move the crosshair across further gauges to extend it. Each gauge that joins is connected to the previous one along its own shortest route, so the dyed path follows exactly the route you traced. While the path is open, every pending link shows a floating green beam, the gauge that a click would confirm is marked with a blinking outline, and the action bar carries the two available gestures. Right-click the last gauge to dye the whole path in one action; right-click the starting gauge, right-click anywhere that is not a gauge, or shift+right-click to cancel. A gauge that cannot join reports the reason instead of failing silently.

**Colour inheritance.** A newly created link inherits the incoming colour of its source gauge, but only when all incoming links share exactly one colour. Mixed or uncoloured inputs remain vanilla.

**Status colours are preserved.** Idle lines are dyed along their entire length. Active lines — in progress, satisfied, failed or flashing — keep their vanilla status-coloured core and gain a one-pixel dye border on each side. The scrolling texture and the restock flashing are unaffected.

**Hover lift and stable picking.** The line under the crosshair is lifted above its neighbours so that crossings and overlaps remain distinguishable, and the selection does not jump between overlapping lines while the crosshair rests on one of them.

**Goggles tracing.** Wearing Create's Engineer's Goggles, rest the crosshair on a dyed line: its whole colour group lights up while every other line of the same factory dims to grey. A readout is appended to Create's own goggle overlay, listing the link and gauge counts of the production line, the idle / running / met / failed breakdown, and the remaining shortage when every gauge in the group requests the same item. Tracing is client-side only, so players on the same server can trace different colours independently.

**Factory Controller support (optional).** With Create: Factory Controller 1.2.1 or higher installed, the virtual connection wires inside the controller GUI can be dyed using the same pick-up-and-apply gesture. The rendering matches the wall, the wire's tooltip names the applied dye in its own colour, and link colours are carried into a board imported from a scanned blueprint. Only ingredient wires are affected; number and redstone wires stay vanilla.

**Redstone and display link lines are never dyed**, because their colour carries status semantics.

## Requirements

| | |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1.x |
| Create | 6.0.10 or higher |
| Create: Factory Controller (optional) | 1.2.1 or higher |

For multiplayer, the mod is required on both the client and the server.

## Configuration

The options live in two standard NeoForge files. In-game config screens such as Configured detect both automatically, and the options and their descriptions are translated into every supported language.

`config/create_colored_connections-common.toml` — server-side flags

| Option | Effect | Default |
|---|---|---|
| `dyeConsumption` | Consume one dye per dyeing action (one per action, not per link) | off |
| `firstGaugeHint` | One-time chat hint on the first factory gauge placed | on |
| `dyeEffects` | Sound and particle feedback when dyeing | on |
| `factoryControllerDyeing` | Dyeing inside the Factory Controller GUI | on |

`config/create_colored_connections-client.toml` — this player's own rendering and tracing options

| Option | Effect | Default |
|---|---|---|
| `hoverLift` | Lift the hovered line above its neighbours | on |
| `gogglesTracing` | Master switch for goggles tracing | on |
| `traceDistance` | Maximum distance, in blocks, for a hover to start a trace | 24 |
| `traceHud` | Trace readout on the goggle overlay | on |

## Languages

English, Simplified Chinese, Russian, German, French, Japanese, Korean, Brazilian Portuguese and European Spanish.

## Data

Colours are stored per dimension in the world save, survive panel relocation and world reload, and synchronise to players on login, dimension change and chunk load. Nothing needs to be configured for this.

## Feedback and licence

Feedback is welcome in the CurseForge comments section. Licensed under MIT; free to include in any modpack without asking.
```

## 三、MC 百科

### 3.1 简介（列表页）

```
使用 16 种原版染料为 Create 工厂仪表的配方连线着色，使交叉密集的产线依然易于辨认。
```

### 3.2 正文

```markdown
Create 的工厂仪表在配方模式下会绘制整面连线。产线越复杂，连线之间的交叉越多，而颜色只反映配方状态，因此难以判断某条连线属于哪个配方。本模组允许使用任意染料为连线着色，使颜色同时承担「归属」的含义。

本模组为客户端与服务端双端模组，多人游戏需两端都安装。

## 运行要求

| | |
|---|---|
| Minecraft | 1.21.1 |
| 加载器 | NeoForge 21.1.x |
| Create | 6.0.10 及以上 |
| Create: Factory Controller（可选） | 1.2.1 及以上 |

开发与运行基线为 Minecraft 1.21.1、NeoForge 21.1.248、Create 6.0.10。Factory Controller 集成为可选：未安装该模组或版本低于 1.2.1 时集成为自动禁用，不会出现崩溃或其他副作用。

## 功能

**单条连线染色。** 手持任意原版染料，右键**连线本身**（而非仪表面板）即可染色，16 种原版染料全部可用。黑色染料用于恢复原版的状态颜色。默认不消耗染料；如需真实成本，可在配置中开启「每次染色消耗一份染料」。

**整条路径一次染完。** Shift+右键某个仪表开始选路，之后将准星依次扫过其它仪表即可逐个接入；每个接入的仪表都沿其自身最短路径与前一个仪表相连，因此染色结果与所选路径完全一致。选路过程中，每条待处理连线会浮起绿色光束预览，将要确认的仪表由闪烁绿框标出，操作栏显示当前可用的两种手势。右键末尾仪表即可一次染完整条路径；右键起始仪表、右键非仪表位置或使用 Shift+右键均可取消。无法接入的仪表会说明具体原因，不会无提示失败。

**颜色继承。** 新建连线会继承来源仪表的入线颜色，但仅当所有入线颜色完全一致时成立；混色或未着色的输入保持原版。

**状态颜色完整保留。** 闲置连线整条染色；处于进行中、已满足、失败或闪烁状态的连线保留原版状态色主体，仅在两侧各增加 1 像素的染料描边，滚动贴图与补货闪烁等动画不受影响。

**悬停抬升与稳定拾取。** 准星指向的连线会被抬升到相邻连线之上，交叉与重叠处因此可以分辨；准星停留在某条线上时，选中状态不会因细微移动而在几条重叠连线之间跳变。

**护目镜追踪。** 佩戴 Create 的工程师护目镜并将准星置于已染色连线上时，同色整组连线一起点亮，同一工厂内其它连线灰化。追踪结果接在 Create 自身的护目镜读数中，包含该产线的连线数与仪表数、闲置／运行／已满足／失败的分类统计，以及整组仪表需求同一物品时该组尚缺的数量。追踪完全在客户端进行。

**Factory Controller 支持（可选）。** 安装 Create: Factory Controller 1.2.1 及以上版本后，控制器界面内的物流连线同样可以染色，操作方式与世界侧一致（将染料拾至光标后右键连线）；悬停提示会用染料本身的颜色显示颜色名；由蓝图扫描导入的接驳板会一并带入连线颜色。仅物流（原料）连线可染色，数字线与红石线保持原版。

**红石与显示连线永不着色。** 其颜色承载状态语义，完全保持原版。

## 配置

配置分为两个标准 NeoForge 文件，游戏内配置界面模组（如 Configured）会自动识别，配置项名称与说明均已本地化。

`config/create_colored_connections-common.toml`（服务端）

| 配置项 | 作用 | 默认 |
|---|---|---|
| `dyeConsumption` | 每次染色消耗一份染料（按操作计，不按连线数计） | 关闭 |
| `firstGaugeHint` | 首次放置工厂仪表时的一次性提示 | 开启 |
| `dyeEffects` | 染色的音效与粒子反馈 | 开启 |
| `factoryControllerDyeing` | Factory Controller 界面内染色 | 开启 |

`config/create_colored_connections-client.toml`（客户端，仅影响本机画面）

| 配置项 | 作用 | 默认 |
|---|---|---|
| `hoverLift` | 悬停时抬升连线 | 开启 |
| `gogglesTracing` | 护目镜追踪总开关 | 开启 |
| `traceDistance` | 触发追踪的最大距离（格） | 24 |
| `traceHud` | 追踪读数显示 | 开启 |

## 支持语言

英语、简体中文、俄语、德语、法语、日语、韩语、巴西葡萄牙语、欧洲西班牙语。术语与 Create 本体对应内容的官方译文保持一致。

## 数据与兼容性

颜色按维度保存在世界存档中，仪表搬移与存档重载均不丢失；玩家登录、切换维度与区块加载时自动同步，无需额外设置。

## 反馈与许可

反馈与建议请发表在 CurseForge 评论区。本模组采用 MIT 许可，允许自由用于任何整合包，无需申请授权。
```
