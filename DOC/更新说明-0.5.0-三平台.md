# Create: Colored Connections 0.5.0 更新说明（三平台）

> 用途：0.5.0 的**版本更新说明**，分别对应 Modrinth 的 Version 页面、CurseForge 的文件 Changelog、MC 百科的更新记录。三处内容一致，仅语言与排版不同。
> 内容取自 `CHANGELOG.md` 的 `## 0.5.0` 段，只保留玩家可感知的变化，内部实现细节（mixin 注入点、字节码核对过程等）不在此重复。
> 项目描述不在本次范围内，各平台现有描述页面保持不变。

---

## 一、Modrinth（Version 0.5.0 · Changelog）

```markdown
### Compatibility

- Now built against Create 6.0.10, the current public release, instead of the 6.0.11 development build. **Create 6.0.10 is the new minimum supported version.**
- Ponder, Registrate and Flywheel are now declared explicitly, at the versions the released Create jar bundles.
- Create: Factory Controller stays an optional integration, never a prerequisite. It is compiled against but not required at runtime: without the mod, or below 1.2.1, the integration simply stays off.

### Configuration

- The config is split into a server file (`create_colored_connections-common.toml`) and a client file (`create_colored_connections-client.toml`), so in-game config editors such as Configured list both. Existing config files migrate automatically.
- The config screen is translated: option names and descriptions now follow the game language, instead of showing raw keys such as `dyeConsumption` and English text.

### Dyeing

- Dyeing reuses the vanilla use action, so a dye click plays the arm swing and the item-use feedback. It still never opens the gauge panel and never places a block.
- Path dyeing follows Create's own connection flow: Shift+right-click cancels a pending chain from anywhere, a plain right-click appends a gauge, and right-clicking the start gauge or anything that is not a gauge cancels.
- A pending chain is explained for as long as it is open: a live action-bar hint, a blinking outline on the gauge a click would confirm, and a concrete reason — reported with Create's deny sound — when a gauge refuses to join.
- Create's gauge hover tip is silenced while a chain is pending, since it advertises an action the chain blocks.

### Rendering

- Preview beams are half as thick (1px) and no longer share space: a crossing reads as a clean cross instead of a darker stepped patch, and a turn at a gauge no longer shows a "+".
- Dyed right-angle corners on active lines no longer show a stepped patch. The dye border sinks one layer step further, so the vanilla line keeps its full corner and the two border bands fill the quadrant the cores leave open.
- The dye border's shade pattern is now exactly as dense as the vanilla line's: every border segment samples the line texture at 1:1, with nothing compressed.

### Languages

- Seven new languages: Russian, German, French, Japanese, Korean, Brazilian Portuguese and European Spanish. Terminology is anchored on Create's own translations and on vanilla's dye and colour names.
- Fixed the goggles trace readout detaching from its item icon — and wrapping mid-sentence — in the longer languages.
- The action-bar path hint is down to the two gestures, which keeps it on screen in every language.
```

## 三、MC 百科（0.5.0 更新说明）

```markdown
### 兼容与依赖

- 编译基线改为 Create 6.0.10（当前公开发布版），最低支持版本同步提升为 **Create 6.0.10**。
- 显式声明 Ponder、Registrate、Flywheel 三个依赖，版本与 Create 发布包内所带一致。
- Create: Factory Controller **保持为可选联动，不是前置依赖**：仅在 1.2.1 及以上版本启用，未安装或版本更低时集成自动关闭，本体与其它功能不受影响。

### 新增

- 配置拆分为服务端与客户端两个文件（`create_colored_connections-common.toml` 与 `create_colored_connections-client.toml`），游戏内配置界面（如 Configured）可自动识别两者；旧配置文件会自动迁移。
- 新增 7 种语言：俄语、德语、法语、日语、韩语、巴西葡萄牙语、欧洲西班牙语，术语与 Create 本体对应内容的官方译文保持一致。

### 调整

- 染色改为复用原版的使用动作：染色时会播放手臂挥动与物品使用反馈，同时依旧不会打开仪表面板、也不会放置方块。
- 路径染色的手势改为与 Create 本体连线操作一致：Shift+右键可在任意位置取消，普通右键接入仪表，右键起始仪表或非仪表位置则取消。
- 选路期间持续给出提示：操作栏显示当前可用手势，将要确认的仪表由闪烁绿框标出；仪表无法接入时会说明具体原因并播放 Create 的拒绝音效。
- 选路期间隐藏 Create 自身的仪表悬停提示，避免提示一个已被选路流程屏蔽的操作。
- 预览光束细一倍（1 像素）且互不重叠：交叉处呈干净的十字，仪表拐角处不再出现 "+"。
- 活动线路的直角转弯处不再出现深色块：染料描边整体下沉一层，原版线条的折角保持完整，两段描边填补核心未占用的那一格。
- 染料描边的花纹密度与本体线条完全一致，不再有压缩感。
- 操作栏提示精简为两种手势，确保在各种语言、各种界面缩放下都不会超出屏幕。

### 修复

- 修复确认染色时会弹出仪表配置界面的问题（染料放在副手时必现）。
- 修复护目镜读数在较长语言下脱离物品图标、跑到图标左侧并中途折行的问题。
- 修复染料描边花纹比本体线条更密的问题。
- 修复路径预览在交叉处出现深色阶梯块、在仪表拐角处出现 "+" 的问题。
```
