# 机械动力：彩色连接线 0.2.0 更新说明

为机械动力（Create）工厂仪表的配方连接线提供 16 种原版染料染色，让密集交错的线路网络一眼可辨。

## 0.2.0 新内容

- **路径批量染色** —— Shift+右键一个仪表开始路径，随后只需将准星扫过更多仪表：每个仪表都会沿它自己的最短线路加入链条，因此染色的路径就是你在网络中实际走过的路线。再次悬停链尾仪表可撤销该节点；右键链尾仪表一键染色整条路径；右键其他任意处取消。构建路径时，沿途每一段待染线路都显示悬浮的绿色光柱预览。
- **染色反馈** —— 染色成功时播放与机械动力仪表连线相同的音效，并沿被染色的连线撒下对应染料颜色的粉尘粒子。
- **配置文件**（`config/create_colored_connections-common.toml`）—— 染料消耗（默认关闭；开启后生存模式下每次操作消耗一个染料，而非每条连线一个）、首次使用提示、染色反馈效果、悬停抬升，均可开关。
- **首次使用提示** —— 第一次放置工厂仪表时，聊天栏会简要说明染色与路径染色玩法，仅提示一次。

## 既有功能（0.1.x）

- **单线染色**：手持任意原版染料右键连接线即可染色；黑色染料恢复原版颜色。默认不消耗染料（生存模式同样免费，可在配置中开启消耗）。
- **智能颜色继承**：新建连线时，仅当源仪表的所有入线颜色完全一致才继承该颜色；混合或未染色的输入保持原版。
- **状态颜色完整保留**：空闲线路完整显示染料颜色；工作中的线路（进行中 / 已满足 / 失败 / 闪烁）保留原版状态色核心，两侧添加 1px 染料色边框；滚动纹理、补货闪烁等动画不受影响。
- **悬停抬升与粘性拾取**：悬停的连接线在交叉处平滑抬升至其他线路之上；拾取具有粘性，高亮不会在交叠线路间跳动，染色点击精确命中屏幕上被抬起的线。
- **红石 / 显示链接线永不染色**：其颜色承载状态语义，保持完全原版。

## 环境要求

| 项目 | 要求 |
|---|---|
| Minecraft | 1.21.1 |
| 加载器 | NeoForge 21.1.x |
| 机械动力 | 6.0.0 及以上 |

多人游戏需要客户端与服务端同时安装。颜色数据按维度存储于世界存档，支持面板迁移与重载；登录、切换维度、区块加载时自动同步，无需任何配置。
