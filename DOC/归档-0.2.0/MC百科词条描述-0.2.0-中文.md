[h1=简介]

用 16 种原版染料为机械动力（Create）工厂仪表的配方连接线上色，让交叉繁杂的工厂网络一眼可辨。dense-network.png

[h1=正文]

本模组为机械动力（Create）6.0新增的工厂仪表系统添加连接线染色功能：手持染料右键即可为配方面板之间的连接线上色，不同配方用不同颜色区分，再密集的工厂网络也能一眼追出每条线通向哪里。

[h2=功能特点]

任意染料右键染色：对准面板之间的连接线本体右键即可着色；黑色染料可重置回原版颜色。默认不消耗染料，生存模式同样免费（可在配置文件中改为每次操作消耗一个染料）。

路径批量染色：Shift+右键一个仪表开始路径，随后将准星扫过沿途的仪表，每个仪表都会沿各自的最短线路自动接入链条——扫过的路线就是染色的路线，遇到分叉由你说了算。构建路径时，沿途每一段待染线路都有悬浮的绿色光柱实时预览。再次悬停链尾仪表可撤销最后一个节点；右键链尾仪表一键染色整条路径；右键其他任意位置取消。

染色反馈：染色成功时播放与机械动力仪表连线相同的音效，并沿被染色的连线撒下对应染料颜色的粉尘粒子。

颜色继承：新建连接线时，若源面板的所有输入连接线恰好同色，新线自动继承该颜色；颜色混杂或未染色时保持原版。

状态颜色完整保留：空闲的连接线整条染成染料色；工作中的连接线（进行中/已满足/失败/闪烁）保留原版状态色主体，仅在两侧各添一条细染料边框，滚动与闪烁动画完全不受影响。

悬停抬升与粘滞注视：注视任一条连接线时，整条线会抬升到邻近线路之上，交叉处也能分清彼此；注视目标具有粘滞性，准星小幅移动时高亮不会在重叠线路间来回跳动。

红石连接线与显示链接线不会被染色：这两类线路的颜色承载状态语义，保持完全原版。

[h2=使用方法]

单线染色：

手持任意一种原版染料；

将准星对准两块面板之间的连接线（线会因悬停而抬升，即为有效目标）；

右键完成染色。默认不消耗染料，可在配置文件中开启消耗（每次操作一个染料）；

黑色染料同理右键，即可恢复原版颜色。

路径批量染色：

Shift+右键起始仪表，开始一条路径；

将准星扫过沿途的仪表，每个仪表自动沿最短线路接入链条，全程显示绿色光柱预览；

染错了？再次悬停链尾仪表即可撤销最后一个节点；

右键链尾仪表，整条路径一次性染色完成；右键其他任意位置则取消本次批量染色。

首次放置工厂仪表时，聊天栏会简要提示染色玩法（仅提示一次，可在配置中关闭）。

[h2=数据与兼容]

颜色按维度存储在世界存档中，面板迁移、重进世界后依然保留；

玩家登录、切换维度、区块加载时自动同步，多人游戏无需任何配置；

配置文件（config/create_colored_connections-common.toml）：染料消耗（默认关闭）、首次使用提示、染色反馈效果、悬停抬升均可开关；

无需任何命令，只有原版染料交互。
