## A. 一句话简介（列表页 / 摘要）

**中文**
用 16 种原版染料给 Create 工厂仪表的配方连线着色——交叉密集的产线，一眼就能读懂。

**English**
Dye the recipe-mode link lines of Create's Factory Gauges with the 16 vanilla dyes, so heavily crossed production lines stay readable at a glance.

## B. 中文完整描述

Create 的工厂仪表在配方模式下会画出一整面连线。产线一复杂，连线彼此交叉，而颜色只反映配方状态——你很难看出哪条线属于哪个配方。Colored Connections 让你拿起任意染料右键连线，把它染成想要的颜色：颜色从此代表「这条线属于谁」，而不只是「现在是什么状态」。

### 功能

- **右键连线染色。** 手持任意染料，右键**连线本身**（不是仪表面板），16 种原版染料全部可用。
- **黑色染料即还原。** 用黑色染料把连线恢复成原版的状态颜色。
- **默认不消耗染料。** 颜色是整理工具，不是消耗品，生存模式反复改色也不会掉染料。希望它有真实成本时，可在配置中开启「每次染色消耗一份染料」。
- **整条路径一次染完。** Shift+右键某个仪表开始选路，之后把准星依次扫过其它仪表即可逐个接入，最后右键末尾仪表一次性染完整条路线。染色期间每条待处理连线都会浮起绿色光束预览，将要确认的那个仪表会被闪烁绿框标出，动作栏持续显示「将染几条连线 / 几个仪表 / 手中染料」；再次看向末尾仪表可撤销它，右键起始仪表、右键空白处或按 Shift+右键都能取消，无法接入的仪表会直接告诉你原因。
- **手感到位。** 染色成功会播放 Create 连接仪表时的同款音效，并喷出一小片对应颜色的粒子。
- **智能继承。** 新建连线会继承来源仪表的入线颜色——仅当所有入线颜色完全一致时；混色或未着色的输入保持原版。
- **状态色完整保留。** 闲置连线整条染色；进行中／已满足／失败／闪烁的连线保留原版状态色主体，只在两侧各加 1 像素的染料描边，滚动贴图与补货闪烁等动画完全照旧。
- **悬停抬升与稳定拾取。** 准星指向连线时，整条线会轻微抬到相邻连线之上（只改变遮挡顺序），交叉、重叠处也能分辨；一旦选中，光标停在线上就不会因为细微移动而在几条线之间跳来跳去，点击目标始终是屏幕上抬起的那条线。
- **护目镜追踪。** 戴上 Create 的工程师护目镜，把准星放在任意已染色连线上：同色整组连线一起点亮，同一工厂内其它颜色的线灰化——密集工厂的「读图」工具。高亮跟随准星，切换颜色时交叉淡入淡出，移开视线即淡出。追踪结果直接接在 Create 自己的护目镜读数里：产线的连线数与仪表数、闲置／运行／已满足／失败的分类统计，以及整组仪表需求同一物品时该组还缺多少。追踪为纯客户端行为，多人游戏中两名玩家可以各看各的颜色。
- **Factory Controller 支持（可选）。** 安装 Create: Factory Controller 1.2.1+ 后，控制器界面里的物流连线同样可以染色：把染料拾到光标上右键连线即可（主手持染料亦可）。界面内的渲染与世界侧一致——闲置线整体染色，活动线保留状态色并加带纹理的染料描边；悬停提示会用染料本身的颜色显示颜色名；用蓝图扫描墙面仪表导入控制器时，连线颜色会一并带入。仅物流（原料）连线可染色，数字线与红石线保持原版。
- **红石与显示连线永不着色。** 它们的颜色承载状态语义，全部保持原版。

### 数据与兼容性

- 颜色按维度保存在世界存档中，跨重载、跨面板移动都不会丢失；玩家登录、切换维度、区块加载时自动同步，无需额外配置。
- 需要 **Minecraft 1.21.1**、**NeoForge 21.1.x**、**Create 6.0.10 或更高版本**。
- 多人游戏中**客户端与服务端都需要安装**。

### 配置

配置分成两个标准 NeoForge 文件，游戏内配置界面模组（如 Configured）会自动识别两者，无需额外适配。

`config/create_colored_connections-common.toml`（服务端）

| 配置项 | 作用 | 默认 |
|---|---|---|
| `dyeConsumption` | 每次染色消耗一份染料（一次操作一份，不是一条线一份） | 关闭 |
| `firstGaugeHint` | 首次放置工厂仪表时的一次性提示 | 开启 |
| `dyeEffects` | 染色的音效与粒子反馈 | 开启 |
| `factoryControllerDyeing` | Factory Controller 界面内染色 | 开启 |

`config/create_colored_connections-client.toml`（客户端，只影响本机画面）

| 配置项 | 作用 | 默认 |
|---|---|---|
| `hoverLift` | 悬停时抬升连线 | 开启 |
| `gogglesTracing` | 护目镜追踪总开关 | 开启 |
| `traceDistance` | 触发追踪的最大距离（格） | 24 |
| `traceHud` | 追踪读数显示 | 开启 |

## C. English Description

Create's Factory Gauges draw a whole wall of link lines in recipe mode. Once a production line gets complex, those lines cross each other constantly — and since their color only reflects recipe status, you can't tell which line belongs to which recipe. Colored Connections lets you pick up any dye and right-click a link to color it: color now means *"this line belongs to this"*, not just *"this is the current status"*.

### Features

- **Right-click a link to dye it.** Hold any dye and right-click **the link itself** (not the gauge panel). All 16 vanilla dyes work.
- **Black dye resets.** Use black dye to restore a link's vanilla status color.
- **Dyeing is free by default.** Colors are an organizational tag, not a crafted product — recolor as often as you like in survival. Prefer a real cost? A config option makes every dyeing action consume one dye.
- **Dye a whole path in one action.** Shift+right-click a gauge to start a path, then sweep your crosshair over further gauges to extend it; right-click the last gauge to dye every link along the route at once. While building, each pending link carries a floating green beam preview, the gauge a click would confirm is boxed by a blinking outline, and the action bar keeps showing the link and gauge counts with the dye in hand. Hover the last gauge again to undo it; right-click the start gauge, right-click anywhere that is not a gauge, or shift+right-click to cancel — a gauge that cannot join says why.
- **Tactile feedback.** A successful dyeing plays the same sound Create uses when two gauges link, plus a small puff of dust in the applied dye's color.
- **Smart inheritance.** A newly created link inherits the source gauge's incoming color — but only when all incoming links share exactly one color. Mixed or uncolored inputs stay vanilla.
- **Status colors stay intact.** Idle lines are fully dyed; active lines (in progress / satisfied / failed / flashing) keep their vanilla status-colored core and gain a thin 1px dye border on each side. Animations like the scrolling texture and restock flashing are untouched.
- **Hover lift and sticky picking.** Looking at a link smoothly lifts the whole line above its neighbors (only the occlusion order changes), so crossed or overlapping links stay distinguishable. Once a line is picked it stays picked while your crosshair is on it — small mouse movements no longer flip the highlight between crossing lines, and the click target is always the line that is lifted on screen.
- **Goggles tracing.** Wear Create's Engineer's Goggles and rest the crosshair on a dyed link: its whole color group lights up while every other line of the same factory dims to gray — the "read my network" tool for dense factories. The highlight follows the crosshair, cross-fades when you switch colors, and fades out as soon as you look away. The readout is appended to Create's own goggle overlay: the link and gauge counts of the production line, the idle / running / met / failed breakdown, and the group's remaining shortage when every gauge requests the same item. Tracing is entirely client-side, so two players can trace different colors of the same network in multiplayer.
- **Factory Controller support (optional).** With Create: Factory Controller 1.2.1+, its virtual connection wires become dyeable inside the controller GUI: pick a dye up onto the cursor and right-click a hovered wire (a dye held in the main hand also works). The rendering mirrors the wall look — idle wires fully dyed, active wires keeping their status core with a textured dye border. The wire's tooltip names the applied dye in its own color, and scanning wall gauges into a blueprint carries their link colors into the imported board. Only ingredient (logistics) wires are affected; number and redstone wires stay vanilla.
- **Redstone and display link lines are never dyed.** Their color carries status semantics and is left fully vanilla.

### Data and Compatibility

- Colors are stored per dimension in the world save and survive panel relocation and world reload. They sync to players on login, dimension change, and chunk load — nothing to configure.
- Requires **Minecraft 1.21.1**, **NeoForge 21.1.x**, and **Create 6.0.10 or higher**.
- For multiplayer, the mod is needed on **both client and server**.

### Configuration

The options live in two standard NeoForge files; in-game config screens (e.g. Configured) pick up both automatically.

`config/create_colored_connections-common.toml` (server-side)

| Option | Effect | Default |
|---|---|---|
| `dyeConsumption` | Consume one dye per dyeing action (one per action, not per link) | off |
| `firstGaugeHint` | One-time chat hint on first factory gauge placement | on |
| `dyeEffects` | Sound and particle feedback on dyeing | on |
| `factoryControllerDyeing` | Dyeing inside the Factory Controller GUI | on |

`config/create_colored_connections-client.toml` (client-side, only affects your own screen)

| Option | Effect | Default |
|---|---|---|
| `hoverLift` | Lift the hovered link above its neighbors | on |
| `gogglesTracing` | Master switch for goggles tracing | on |
| `traceDistance` | Max distance (blocks) for a hover to start a trace | 24 |
| `traceHud` | Trace readout on the goggle overlay | on |
